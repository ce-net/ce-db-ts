# ce-db-ts: typed state.store collections for TypeScript (`@ce-net/db`)

Slice 1 of `repo:state-store-cell/docs/DB-SDK-DESIGN.md`, the TypeScript half beside `repo:ce-db-rs`. The schema is a
Rust struct with `#[derive(Record)]`; `ce-wire-gen --records <schema crate>/src/lib.rs --lang ts -o sdk/ts` (or
`--lang ts-web`) writes the typed collection, and this package is its runtime, in node and in the browser.

```ts
import { open } from '@ce-net/db';                        // browser: '@ce-net/db/web'
import { parts, type Part } from './sdk/ts/parts-demo.js'; // generated
const db = await open('parts-demo');                       // node: $CE_DB_STORE + $CE_DB_CAP, or state.store by name
const p = parts(db);
const id = await p.insert({ name: 'M3x8 screw', bin: 'A4', qty: 500 });   // the ULID key is made when left out
const one: Part | undefined = await p.get(id);
await p.update(id, (x) => { x.qty -= 1; });                // Patch of the changed fields only
const inA4 = await p.byBin('A4').limit(50).fetch();
const low = await p.byQty({ lt: 20 }).desc().fetch();
for await (const ch of await p.byBin('A4').watch()) console.log(ch.kind); // added | changed | removed | synced
const live = p.byBin('A4').store();                        // React: useSyncExternalStore(live.subscribe, live.getSnapshot)
```

- Same surface, rules and encoding as ce-db-rs, checked byte for byte by `repo:db-conformance` (D1 golden values).
  `u64`/`i64` are `bigint` (decimal strings on the wire), bytes `Uint8Array` (hex), optionals absent, `_v` kept.
- Errors are `DbError` with `info.kind`: `NotFound`, `Conflict { heldVersion }`, `Invalid { field, why }`,
  `Refused { need }`, `TooLarge { bytes, limit }`, `Throttled`, `SchemaMissing`, `SchemaBehind`,
  `Unavailable { tried }`, `NeedsServerIndex`, `Store { message }`.
- Transport: the ce-wire `state.store` client generated by `ce-wire-gen --lang ts` / `--lang ts-web` from
  `repo:state-store-cell/crates/state-store-api/src/lib.rs` (`src/wire/`, schema `0x054ed03aa6aa8fc1`; regenerate with
  `npm run gen`, never edit). Node dials TCP; the browser speaks ce-wire through a WebSocket door (`wire.ws-door`, or a
  cell's own dev pipe), with the grant and cap in the link fragment (`#cap=...&g=...&w=...`).
- The first use of a collection reads the registered schema and registers this program's when it is missing or
  older (needs `state.<app>.admin`), else `SchemaMissing`/`SchemaBehind`. `open` dials at once with a 2 s deadline.
- Index queries and watches come from one live mirror per collection (List with tombstones, then Watch), at most
  `mirror_limit` rows; prefix and all() are op 4 List pages.

Not in slice 1: the browser's IndexedDB cache and offline outbox (DB-SDK-DESIGN 4.2), wallet lookup of grants in
node (pass `cap`, `$CE_DB_CAP` or `~/.config/ce-state/<app>.cap`), CRDT and ledger collections.
